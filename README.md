# pairwise-punchin-monitor-latency

## 领域

游戏、图形与多媒体

## 主题

录音监听延迟补偿

## 说明

往返延迟测量、采样对齐与环缓栅栏。

初始状态下 `media/punchin_monitor_latency.py` 中所有函数抛出 `NotImplementedError`，测试全部失败。
修复实现后运行：

```bash
python -m pytest -q
```

期望全部通过（15 个契约测试 + 29 个行为回归测试，共 44 个）。

## 缺陷与修复映射

| # | 原始缺陷 | 修复入口 | 修复方式 |
|---|---------|---------|---------|
| 1 | 输入缓冲直送监听输出，声卡往返延迟未补偿，监听与伴奏错开半拍 | `measure_latency` / `fallback` / `monitor_path` / `DelayLine` | 环回探针 + 定窗归一化互相关测量往返延迟（置信度不足走标称值兜底），监听链路串入等长延迟线，把监听信号推后整段往返延迟 |
| 2 | punch-in 起止点按采样计数落在缓冲边界外被截断 | `sample_align` / `punch_range` | 起点向下、终点向上对齐块边界，钳制在录音时长内；落盘仅接受整块完整位于区间内的块，部分相交一律不取 |
| 3 | 设备切换后采样率变化，补偿量仍按旧采样率计算 | `device_recalc` | 物理往返延迟以秒为设备常量，切换后按 `round(seconds * new_rate)` 重算补偿采样数并重建延迟线 |
| 4 | 录音/混音线程共享环形缓冲，读写指针无栅栏导致丢帧 | `RingBuffer` / `ring_fence` | SPSC 模型，槽位写入与指针发布之间插入 acquire/release 栅栏（锁 + 条件变量承载），支持阻塞背压；非阻塞路径满时计数丢帧且不覆盖未读数据 |
| 5 | 暂停恢复后监听缓冲未清空，旧片段叠进新录段 | `buffer_clear` | 栅栏保护下复位读写指针并递增 generation，旧代数据对读者立即失效，并唤醒所有等待线程 |
| 6 | 混音未按时间轴对齐 | `timeline_align` / `mix` / `record` | 录段锚定主时间轴秒位置（监听延迟线已补偿，不二次扣减）；跨采样率先换算到秒再线性重采样；punch 区间内 replace 伴奏、区间外保留伴奏 |

辅助入口：`validation`（入参校验）、`audit`（逻辑时钟审计轨迹）、
`metrics`（指标快照）、`determinism`（同种子逐采样可复现）。

纯标准库实现，无第三方依赖。
